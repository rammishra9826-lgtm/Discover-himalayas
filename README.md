# Discover Himalayas

A website for exploring the Himalayas, built with React and Vite.

## Tech Stack

- React
- Vite
- Tailwind CSS
- Framer Motion

## Getting Started

```bash
# Install dependencies
npm install

# Start the dev server
npm run dev

# Create a production build
npm run build
```
